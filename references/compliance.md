# 合规红线与自检 rubric

本文件是**一票否决**依据。生成任何提示词前先读，输出前逐项打勾。

## 一、硬红线（不可协商）

1. 主体必须是**成年女性 / 成年模特**，任何未成年角色或未成年人一律不做。
2. 服装完整，**不写裸露、不写性暗示、不写带有性取向的姿势与形容**。
3. 不做真人明星换脸、不冒充特定真人的照片、不使用可识别的真人肖像指向。
4. 不协助绕过任何平台的审核机制。
5. 不生成数字绘画 / 3D CG 动画风内容 —— 本 skill 只做真人写实摄影，两套画风互斥。
6. 角色版权归原作者，配方仅作个人学习与创作参考，禁止商用与二次分发。

**处理方式**：遇到越界请求，先说明不能做，再主动把需求**改写成合规版本**（保留服装、材质、构图与光线细节，去掉暴露、暗示与身份指向），然后继续正常输出。不要只拒绝不给出路。

## 二、10 项自检 rubric

| # | 检查项 | 判定依据 | 级别 |
| --- | --- | --- | --- |
| 1 | 主体明确为成年女性 | 出现「成年女性 / 成年模特」 | 一票否决 |
| 2 | 服装完整、无裸露与性暗示 | 无越界形容，且衣物描述完整 | 一票否决 |
| 3 | 无未成年、无真人明星肖像 | 无相关指向 | 一票否决 |
| 4 | 构图为腰部以下下半身、完整双腿与脚部 | 出现对应构图句 | 一般 |
| 5 | 材质五要素齐全 | 编织结构 / 透肤度 / 厚度 / 弹性 / 贴合 | 一般 |
| 6 | 光泽为纤维光泽且排除塑料橡胶 | 出现「纤维光泽」「不是塑料或橡胶反光」 | 一般 |
| 7 | 保留皮肤纹理、毛孔与肤色变化 | 出现「皮肤纹理」「自然毛孔」 | 一般 |
| 8 | 明确真实照片、非绘画非 3D 渲染 | 出现结尾排除句 | 一票否决 |
| 9 | 镜头与质感齐全 | 85mm / 全画幅 / RAW / 光学景深 / 自然光 / 环境反射 | 一般 |
| 10 | 输出结构 5 段齐全 | 5 个【】段落 + 英文关键词 + 负面词 | 一般 |

**判定规则**：第 1、2、3、8 项任一不通过 → 改写后重出，不得交付；一般项不通过 → 补齐或在【自检结论】里注明已调整。

## 三、常见越界请求的合规改写

| 用户原话 | 改写后 |
| --- | --- |
| 「写点更撩人的姿势」 | 保留自然放松的坐姿与材质特写，去掉带暗示的姿势形容，改为「双腿自然放置、姿势放松、符合真实人体结构」 |
| 「用某真人女明星的脸」 | 去掉真人身份指向，改为「以参考图中的游戏角色服装与造型为参考，呈现为一位成年女性模特」 |
| 「未成年角色 / 学生制服感」 | 明确不生成未成年主体；改为成年女性模特 + 保留服装配色与丝袜款式，不含任何校服年龄指向 |
| 「要动漫风 / 3D CG 那种丝袜」 | 说明本 skill 只做真人写实，转交对应的 CG 风格分支，不混用词块 |

## 四、画风互斥（重要）

以下词块属于**日系 3D CG 动画风**，与本 skill 的真人写实定位冲突，出现即会让画面变成手办感，**禁止写入本 skill 的输出**：

`cinematic Japanese 3D CG animation still`、`semi-realistic stylized CG`、`soft painted CG shading`、`luminous rim light`、`strong glowing bokeh`、`creamy Cooke lens rendering`、`soft daylight global illumination`

对照：本 skill 用的是 `Photorealistic`、`Ultra-realistic photography`、`Live-action cosplay photography`、`Real human anatomy`、`Fine nylon weave`、`Real-world lighting`、`85mm lens`、`RAW photo quality`。

## 五、平台适配提醒

- 不同出图平台对提示词的审核口径不同，同一段词可能被截断或拒收；遇到拒收时优先删减长度，不要为了过审而弱化「成年 / 服装完整 / 真实照片」这些关键限定。
- 需要英文 prompt 时，把中文逐句直译，保留 `adult`、`fully clothed`、`photorealistic`、`natural skin texture`、`85mm lens` 等关键词。
- 附角色参考图时，仅用于服装与配色参考，不得用于指向真实人物身份。
