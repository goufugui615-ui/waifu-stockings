# 要素库（9 组）

按顺序逐项确认，用户没指定的项用「基准值」补全，并在输出的【参数建议】里标注为默认值。**不要自行编造角色设定**。

## 1 · 画幅

| 值 | 适用 |
| --- | --- |
| `3:4` | 竖版材质特写，默认推荐 |
| `9:16` | 手机竖屏、腿部纵向延展 |
| `4:3` | 近距离织物细节 |
| `16:9` | 环境占比更大的时尚编辑构图 |

## 2 · 材质（决定编织结构怎么写）

| 材质 | 编织结构描述 | 写法要点 |
| --- | --- | --- |
| 尼龙丝袜（基准） | 细密、均匀的尼龙纤维编织结构 | `fine nylon weave`，最通用的写实基准 |
| 包芯丝 | 细密纵向纹路、微哑光 | 强调纵向拉伸与回弹 |
| 天鹅绒 / 哑光 | 短绒面、低反光 | 强调漫反射，弱化高光 |
| 网纹 / 蕾丝 | 明确的网眼或花纹单元 | 强调单元尺寸均匀、边缘清晰 |
| 罗纹 / 竖纹 | 可见纵向凸棱 | 强调棱线随腿部曲面弯折 |
| 压力 / 厚织 | 高密度、几乎不透 | 强调厚度与不透明度 |

## 3 · 丹尼尔与透肤度

| 丹尼尔 | 透肤 | 提示词写法 |
| --- | --- | --- |
| 5–15 D | 近乎透明 | 极薄、隐约透出肤色、膝盖与脚踝处更透 |
| 20–30 D（基准） | 半透 | 自然透肤程度，肤色在织物下柔和显现 |
| 40–60 D | 微透 | 织物厚度可见，肤色仅在高光处隐约透出 |
| 80 D 以上 | 基本不透 | 不透明度高，重点写织物厚度与表面纹理 |

## 4 · 颜色与配色

`肤色 / 裸粉`、`黑色`、`炭灰`、`藏青`、`白色`、`象牙`、`角色标志色`。
写法：颜色 + 均匀度 + 与服装配色的关系（例：「与原角色深色裙装形成克制的明暗对比」）。避免使用会让人联想到裸露的形容词。

## 5 · 花纹与边缘设计

- 花纹：`纯色` / `波点` / `菱格` / `竖纹` / `网眼` / `提花` / `角色标志性图案`
- 边缘：`罗口` / `蕾丝边` / `吊带接口` / `缝线` / `无痕` / `加固袜头`
- 写法：严格遵循参考角色设计，**明确写出位置**（大腿、膝上、脚踝、袜头），不要凭空新增。

## 6 · 场景（基准场景优先）

| 场景 | 环境细节 |
| --- | --- |
| 纯白棉床单卧室（R01 基准） | 柔软大床、白色棉质床单 / 羽绒被 / 枕头，真实织物纹理与自然褶皱，简洁干净 |
| 窗边 | 窗框、薄纱、窗台，光从侧前方来 |
| 摄影棚 | 无缝背景纸、柔光箱、反光板 |
| 更衣室 / 沙发 | 木质或布面、镜面反射，注意反射里不出现多余人物 |

## 7 · 光线（写实版，禁止套用 CG 动画风词块）

| 光线 | 中文写法 | 英文关键词 |
| --- | --- | --- |
| 窗户柔和自然日光（基准） | 窗户透入柔和的自然日光，无硬阴影 | `soft natural window daylight, real-world lighting` |
| 窗边侧逆光 | 侧逆光沿腿部轮廓形成克制的丝质高光 | `gentle rim highlight, natural falloff` |
| 柔光箱棚拍 | 大面积柔光，织物纹理均匀可辨 | `large softbox, even diffuse light` |
| 夜景实用光 | 室内灯具与窗外城市光，暖冷对比 | `practical lighting, real environment reflection` |

> 注意：本 skill 是真人写实摄影。**不要**使用 `soft painted CG shading`、`luminous rim light`、`glowing bokeh`、`cinematic Japanese 3D CG animation still` 这类日系 CG 动画风词块，它们会把照片拉成手办感。

## 8 · 镜头与质感（骨架句，不可省略）

`专业全画幅相机` + `85mm 人像镜头` + `自然光摄影` + `真实光学景深` + `RAW 照片质感` + `细腻的真实皮肤纹理` + `自然毛孔` + `细微肤色变化` + `准确的自然阴影` + `真实环境反射` + `膝盖 / 腿部曲线 / 脚踝的织物贴合`。

结尾必须加：「最终效果必须像现实中由专业摄影师拍摄的真实照片，而不是任何形式的数字绘画或电脑生成的 3D 渲染。」

## 9 · 负面词库

| 类别 | 词 |
| --- | --- |
| 画风类 | 数字绘画、3D 渲染、CG、插画、动漫、手办感、蜡像、卡通 |
| 材质类 | 塑料反光、橡胶质感、镜面高光、过度磨皮、织物纹理缺失、均匀无纹路的假腿 |
| 人体类 | 人体畸变、多余肢体、比例失调、裁切脚部、脚趾缺失、姿势僵硬 |
| 合规类 | 裸露、色情暗示、未成年、真人明星换脸、冒充真实照片、水印、文字、logo |

## 基准规格（用户未指定时套用）

`尼龙丝袜` + `20–30 D 半透` + `角色原设颜色` + `纯色无花纹` + `罗口` + `纯白棉床单卧室` + `窗户柔和自然日光` + `3:4` + `85mm 全画幅 RAW`。
